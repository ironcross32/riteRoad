# Changelog

Each version's section is the release notes riteRoad shows when it offers that update. Add one
before tagging the version; the release fails without it.

## 0.1.0

The first release.

- Control the RØDE Wireless Micro receiver's output mode, output gain, LED brightness and each
  transmitter's noise reduction.
- Read the receiver's and transmitters' status, and hear it from anywhere with Ctrl+Shift+F9.
- Spoken announcements when the receiver or a transmitter connects or disconnects, and when a
  battery runs low.
- Runs from any folder with its settings beside it, or installs itself to this PC.
- Checks for updates when it starts.
